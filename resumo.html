⚙️PROJETOS

O OCOSS é um assistente virtual interativo em linha de comando desenvolvido em Python para facilitar o acesso rápido a aplicativos do sistema e sites no Windows.Visão Geral O programa executa um loop contínuo no terminal que aceita entradas de texto do usuário e dispara ações automatizadas.
Funcionalidades
Calculadora: Abre o utilitário nativo de calculadora do Windows.
Previsão do Tempo: Permite abrir o aplicativo nativo de clima (Bing Weather) ou realizar uma busca direta no Google.
Spotify: Oferece menu para abrir o aplicativo desktop instalado ou a versão web no navegador.

Atalhos Web: Redireciona o usuário diretamente para as páginas do Instagram e do YouTube no navegador padrão.
Menu e Navegação: Fornece o comando `ajuda` para listar as opções disponíveis e `sair` para encerrar o programa com segurança.

Requisitos Técnicos
Linguagem: Desenvolvido em Python 3.12, utilizando apenas as bibliotecas nativas `os` e `webbrowser`.

Compatibilidade: Voltado para o sistema operacional Windows devido ao uso de comandos específicos como `calc` e a sintaxe `start` para chamadas do sistema.
